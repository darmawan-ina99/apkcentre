Cara memverifikasi di HP Android:

1. Buka aplikasi file manager, cari file APK yang didownload
2. Buka file dengan fitur "Details" atau install aplikasi pembuat checksum (contoh: Hash Droid)
3. Hitung MD5 file, lalu bandingkan dengan daftar di atas
4. Kalau cocok = file asli dari APKCentre. Kalau beda = file telah dimodifikasi orang lain, jangan diinstall
